|------|------|
| **厂商** | 腾讯云 |
| **类型** | 安全漏洞 |
| **发现时间** | 2026-06-18 |
| **影响范围** | Linux Kernel 5.18 ~ 7.1-rc7 |
| **紧急程度** | 🔴 高 |
| **CVE编号** | CVE-2026-46331 |

**摘要**：Linux Kernel 被披露存在本地权限提升漏洞。攻击者可通过创建用户命名空间并获取 CAP_NET_ADMIN 能力，利用 act_pedit 模块的 COW 页缓存损坏漏洞，篡改 setuid-root 文件的页缓存内容，将权限提升至 root。POC已公开。

**用户行动建议**：
1. 评估业务是否使用 act_pedit 模块
2. 升级内核至 >= v7.1-rc7
3. 或使用缓解措施：安装 block-cve-2026-46331.conf 禁用 act_pedit 模块
